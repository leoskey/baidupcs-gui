# 品牌图形：云中箭

BaiduPCS-Go 桌面 GUI 的图形标。几何云（三圆 + 圆角底）里用圆角镂空切出一支下箭头，云体从上传蓝过渡到下载绿，与传输监视器胶囊的配色一致。暂未确定产品名，所以只有图形标，没有文字标。

| 文件 | 用途 |
| --- | --- |
| `mark-color.svg` | 彩色图形标，透明底（文档、网页、浅色或深色背景）。程序在编译时嵌入它作为胶囊与面板标题的图形标，加载时把 viewBox 裁成贴合云朵的 `15 15.5 70 70`（见 `src/ui.rs` 的 `Assets`），改动此文件后需重新构建程序 |
| `mark-mono.svg` | 单色图形标，颜色跟随 `currentColor`（单色印刷、系统托盘单色主题） |
| `app-icon.svg` | 应用图标源文件：深色圆角底 + 图形标，云宽约占 75% 以保证 16px 可辨 |
| `app-icon.ico` | Windows 图标，内含 16/20/24/32/40/48/64/256px，每帧都是该尺寸的原生渲染 |
| `png/app-icon-*.png` | 16–1024px 应用图标 |
| `png/mark-color-1024.png` | 1024px 透明底彩色图形标 |

## 规格

| 项 | 值 |
| --- | --- |
| 上传蓝（渐变起点） | `#4C9EFF` |
| 下载绿（渐变终点） | `#3DDC97` |
| 图标底色 | `#111418`，圆角为边长的 22% |
| 渐变方向 | 左上 → 右下（`userSpaceOnUse`，整朵云连续过渡，不按单个圆分别渐变） |
| 箭头镂空 | 线宽 8（100 单位画布），圆角端点与转角 |

## 修改后重新导出

改动 SVG 后运行：

```powershell
python export.py
```

脚本用无界面 Edge 按每个尺寸原生渲染，重写 `png/` 和 `app-icon.ico`，并校验 ICO 每帧与原生渲染一致、四角透明。依赖 Microsoft Edge 与 Pillow。
